Keys and conventions

read this first

Every MATHKIT program reads its inputs the same way, pages its work the same way and writes answers with the same symbols. Learn these once.

B.1Starting a program

  1. Press prgm, move to MATHKIT and press enter. The home screen shows prgmMATHKIT.
  2. Press enter again to run it.

Each program can also run on its own the same way, for example prgmZQSOLV. Programs whose names start with ZL, and ZEXPR, are helpers that the others call: never run them directly.

To stop a running program, press on, then choose 1:Quit.

B.2Keys that matter

(−)
The negative sign, bottom row. Use it for every negative number: ⁻12. The − key above + is subtraction and gives ERR:SYNTAX at the start of an entry.
x,T,θ,n
Types X. Always use X in a typed expression, even when the book writes p, t or u.
2nd (   2nd )
The list braces { and }.
÷
Types the fraction bar /. ⁻13/16 stays an exact fraction.
x²   ^
Squares, and higher powers: X^4.
2nd math
The test menu, for = in ZCHECK.
alpha
A letter, for example the function letter N in ZRATFN.

B.3Typing values

Every prompt takes text, so any of these forms works wherever a number, a list or a polynomial is asked for:

TypeMeans
5   ⁻12a number
1/4   ⁻13/16a fraction, kept exact
4.9   .04a decimal. The whole problem then answers in decimals, 4 places.
{1,⁻6,⁻7}coefficients, highest power first. Put 0 for a missing power: x³ − 2x − 5 is {1,0,⁻2,⁻5}.
3(X+1)(X-1)the polynomial as printed, multiplied out exactly by MATHKIT

Typed polynomials go up to degree 6 (ZPOLY's COEFFICIENTS option goes to 10). MATHKIT checks its expansion at two extra points. A quotient such as 1/(X-5), or anything that fails the check, gives NOT A POLYNOMIAL OF DEGREE ≤6 and returns to the menu.

Pressing enter without typing anything counts as 0.

B.4Paging the work

The work comes one step per screen. The top line reads page/total TITLE, for example 3/6 4*3=12, ADD.

enter ▼ ►
Next page. On the last page, finish.
▲ ◄
Previous page.
clear
Jump to the first ANSWER page. Press it again to finish.

A step longer than 8 lines continues on a page marked (CONT). A GRAPH page switches to the graph screen; press enter to go on. Your window settings are put back afterwards.

The calculator has no character for some textbook symbols, so MATHKIT writes them this way:

⁻ is a negative number and - is subtraction. The imaginary unit is the calculator's own italic 𝑖.

B.6Show work or answer only

In MATHKIT, 7:SETTINGS / QUIT holds the switch: 1:SHOW ALL WORK or 2:ANSWER ONLY. It stays set, even for programs started on their own.

In answer-only mode the first screen is the answer, for example 1/1 ANSWER. Use it to check homework quickly; switch back to see how the answer was reached.

B.7When something goes wrong

a message
For example A CANNOT BE 0 or DENOMINATOR CANNOT BE 0. Press enter: you return to the program's menu to try again.
ERR:SYNTAX
A typo, such as − used for a negative. Choose 1:Quit and run the program again. TI-BASIC cannot catch errors, so MATHKIT cannot recover from these itself.
ERR:DATA TYPE
A list typed where one number belongs. Quit and run again.

MATHKIT overwrites Str0–Str9 and the letters A–W, Y, Z and θ. It never touches your Y= functions, and it puts your X back when a program ends normally.

prgmZCPLX

Complex numbers

MATHKIT > 1

Rewrites (A+B√(⁻N))/D with 𝑖, simplifies the radical and splits the fraction. Adds, subtracts or multiplies two complex numbers with FOIL and 𝑖²=⁻1. Every answer is exact, in a+b𝑖 form.

On screen: Form B 1e with every page of work, then 2e jumping straight to the answer with clear.

C.1Pick the option

OptionUse it forForm B
1:SIMPLIFY (A+B√(⁻N))/Done expression with a square root of a negative, possibly over a denominator1a–f
2:ADD(a+b𝑖)+(c+d𝑖)2a
3:SUBTRACT(a+b𝑖)−(c+d𝑖)2b
4:MULTIPLY(a+b𝑖)(c+d𝑖), including products of √(negative)2c–e

C.2What to type

SIMPLIFY
A=? B=? N=? D=? for (A+B√(⁻N))/D. Whole numbers, N > 0, D ≠ 0. A minus in front of the root is B = ⁻1; no denominator is D = 1.
ADD, SUBTRACT, MULTIPLY
The first number as A, B, N for A+B√(⁻N), then the second as C, D, N. For an ordinary a+b𝑖 use N = 1. N must be a perfect square (1, 4, 9, …) because √(⁻9) = 3𝑖.

Form B 1e, (−12 − √(−144))/(−4), is A=⁻12, B=⁻1, N=144, D=⁻4. Form B 2e, (8 − √(−9))(4 + √(−16)), is A=8, B=⁻1, N=9 and C=4, D=1, N=16.

For SIMPLIFY, Form B 1e produces these pages:

C.4Reading the answer

A fractional part is written in parentheses before the 𝑖, for example 3/4+(7/8)𝑖. A radical part keeps its root after the 𝑖: 6𝑖√(5).

C.5Messages

USE WHOLE NUMBERS, N>0 AND D≠0
SIMPLIFY got a fraction, a decimal, N ≤ 0 or D = 0.
N MUST BE A PERFECT SQUARE
Arithmetic needs N = 1, 4, 9, … Simplify a root like √(⁻12) with option 1 first.

C.6Procedure

flowchart TD
  s(["prgmZCPLX"]) --> m{"COMPLEX menu"}
  m -- "1 SIMPLIFY" --> a["A, B, N, D"] --> b["Split off ⁻1: √(⁻N) = 𝑖√(N)"]

  m -- "2, 3 or 4" --> g["1ST: A, B, N then 2ND: C, D, N"] --> h["Convert each √(⁻N) to 𝑖√N"]

  m -- "5 BACK" --> q(["MATHKIT"])

MATHKIT > 2 > 1

On screen: 8d typed as printed, 12i by the formula from coefficients, and 10c with fractions.

prgmZRATEQ

Rational equations

MATHKIT > 4 > 1

Solves an equation of fraction terms: restrictions, the LCD, the equation multiplied through, solving, and a check of every candidate. Excluded values are marked extraneous; each kept root is substituted into both sides.

On screen: 30f through all eight pages; 30c, where 5 is rejected, ending on its CHECK page.

E.1What to type

1:SOLVE EQUATION
The only option besides BACK.
LEFT TERMS=? RIGHT TERMS=?
How many fraction terms on each side: 1–4 per side, 5 in all.
NUM= DEN=
For each term, its numerator and denominator, as a list or typed. A term with no denominator has DEN = 1.

Put a term's minus sign on its numerator: −8/(x+3) is NUM = ⁻8, DEN = X+3. Form B 30f is 2 terms left, 1 right: 11 over X−3, ⁻8 over X+3, and 9 over X²−9.

E.2The work pages

RESTRICTIONS factors each denominator and lists the excluded values. MULTIPLY BY THE LCD shows each term after its denominator cancels. CHECK handles every candidate.

E.3The check page

A root equal to an excluded value is never substituted (it would divide by zero). It is reported as extraneous, and the answer lists it after the solution set: {1}, 5 IS EXTRANEOUS. When every candidate is excluded the answer is NO SOLUTION.

E.4Messages and speed

USE 1 TO 4 TERMS PER SIDE
A term count of 0, or more than 4.
DENOMINATOR CANNOT BE 0
A DEN of 0.

ZRATEQ does the most work in the kit; expect about five seconds before the first page.

E.5Procedure

flowchart TD
  s(["prgmZRATEQ"]) --> m{"RATIONAL EQUATION menu"}
  m -- "1" --> n["Terms per side, then NUM and DEN for each"] --> r["Factor denominators, list excluded values"]
  r --> l["LCD"] --> mu["Multiply every term by the LCD"] --> co["Collect on one side"] --> so["Solve the polynomial"]
  so --> ck{"Each candidate excluded?"}
  ck -- "yes" --> ex["Extraneous"] --> ans
  ck -- "no" --> sub["Substitute into both sides, show MATCH"] --> ans["ANSWER: solution set"]
  ans --> m

prgmZCHECK

Check an answer

MATHKIT > 6 > 2

Substitutes an x value into any expression or equation and shows each side's value and whether they match. Use it on your own answers to any problem.

On screen: checking x = 1/3 in 3x²+8x−3 = 0, then refusing x = 5 in 1/(x−5).

K.1What to type

  1. At ? type the expression or equation with X. Get = from 2nd math.
  2. CAN IT BE UNDEFINED? 1:NO, or 2:YES, LIST BAD X if X appears in a denominator. Then type the bad values at EXCLUDED=, as a list {5} or a number.
  3. X VALUE=, for example 1/3.

Afterwards a menu offers 1:SAME, NEW X, 2:NEW EXPRESSION or 3:BACK.

K.2Reading the answer

For an expression without =, the answer is its value, for example F(7)=1/2.

K.3Why it asks about undefined points

TI-BASIC cannot catch errors. Substituting x = 5 into 1/(x−5) would stop the program with ERR:DIVIDE BY 0. Declaring the bad values lets ZCHECK say X=5 IS EXCLUDED instead, which is also the right conclusion for a rational equation: that root is extraneous (see E.3).

K.4Procedure

flowchart TD
  s(["prgmZCHECK"]) --> e["Expression or equation"] --> u{"CAN IT BE UNDEFINED?"}
  u -- "NO" --> x["X VALUE="]
  u -- "YES" --> b["EXCLUDED= values"] --> x
  x --> c{"X excluded?"}
  c -- "yes" --> no["X IS EXCLUDED, no substitution"] --> nx
  c -- "no" --> sv["Evaluate each side"] --> mt["SIDES MATCH or SIDES DIFFER"] --> nx{"SAME, NEW X / NEW EXPRESSION / BACK"}
  nx -- "1" --> x
  nx -- "2" --> e
